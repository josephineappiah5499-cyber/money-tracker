# Money Tracker

An interactive personal finance dashboard built with Python, pandas, and Streamlit.

## Features
- Monthly income, expenses, giving, and savings overview
- Individual category tracker
- Month filter
- Interactive charts
- Downloadable monthly summary

## Tools
- Python
- pandas
- Streamlit

## How to run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Privacy
This repository excludes personal financial data.
